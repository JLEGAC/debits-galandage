OUTIL DE DIMENSIONNEMENT

Préparation des débits

Saisissez les dimensions connues dans le sens qui vous convient. Les cotes liées se calculent dans les deux sens, puis les débits documentés sont listés.

01

Configuration

Choisissez la porte et les options du projet.

Le type de remplissage est repris sur le récapitulatif. Aucune différence de formule ou de débit selon le remplissage n’a encore été définie.

02

Cotes du projet

Vous pouvez saisir plusieurs cotes connues. Les résultats sont recalculés automatiquement, quelle que soit la cote de départ.

Toutes les valeurs sont en millimètres. Une cote calculée peut aussi être saisie pour démarrer le calcul depuis celle-ci.
